// Criar uma Live Stream (Streamer)
const live = await Video.live("minha-super-live");

Salas e Chamadas

Crie chamadas 1x1 ou salas de reunião em malha (Mesh P2P) onde todos se veem. A biblioteca gerencia toda a sinalização e reconexões automaticamente se a internet cair.

💻 Frontend (Navegador) 
const sala = await Video.sala("reuniao-equipe");
await sala.entrar();

sala.on('video', ({ usuario, stream }) => {
  // Novo participante chegou!
  anexarVideoNaTela(usuario.id, stream);
});

Transmissões ao Vivo

Um transmite, muitos assistem. Economize banda usando o modo Live, onde espectadores apenas recebem o fluxo de dados sem sobrecarregar a rede do Streamer.

💻 Frontend (Navegador) 
// No cliente que vai apenas assistir:
const live = await Video.assistir("gameplay-lol");

live.video(document.getElementById('player'));
await live.conectar();

VOD, Upload e Download

Não é só tempo real. O servidor embutido lida com arquivos físicos. Faça upload, liste vídeos e reproduza com suporte nativo a HTTP Range Requests (permite avançar o vídeo sem baixar tudo).

💻 Frontend (Navegador) 
// Enviar um arquivo do input file
await Video.enviar(arquivoSelecionado);

// Reproduzir direto do servidor
await Video.reproduzir(urlDoVideo, player);

O Servidor de Sinalização (Backend)

Para que os navegadores conversem entre si, precisamos de um servidor Node.js intermediário. A videolib faz o setup pesado para você.

⚙️ Backend (Node.js) 
import express from 'express';
import { VideoServer } from '@caiomultiversando/videolib/server';

const app = express();
app.get('/', (req, res) => res.send('Meu App Express!'));

// 1. Sobe seu servidor normal
const httpServer = app.listen(3000);

// 2. Acopla o VideoServer nele (Sem conflito de portas!)
const video = new VideoServer();
video.videos('./meus-videos'); // Serve arquivos para VOD
video.anexar(httpServer);

Controles Avançados (Mute, Câmera e Tela)

A manipulação de mídia funciona em tempo real. Você pode substituir a câmera pela tela do PC sem derrubar a chamada.

💻 Frontend (Navegador) 
// Mutar e Desmutar microfone
sala.mute();
sala.desmutar();

// Pausar o próprio vídeo (imagem preta)
sala.pausarCamera();
sala.retomarCamera();

// Compartilhar a tela do PC (Substitui a câmera local)
await sala.tela();

// Voltar para a câmera normal
await sala.pararTela();

Reconexão Automática (Backoff)

A internet caiu? O usuário trocou do 4G para o Wi-Fi? A biblioteca tenta se reconectar sozinha e reentra nas salas.

💻 Frontend (Navegador) 
sala.on("reconectando", (info) => {
  console.log(`Conexão perdida. Tentando novamente... ${info.attempt}/${info.maxAttempts}`);
});

sala.on("reconectado", () => {
  console.log("Restaurado! Estamos de volta à sala.");
});

Referência da API Frontend

Método / Classe Descrição
Video.configure(opts) Configura o WebSocket e URL do servidor.
Video.chamada(id) Cria uma Call P2P 1x1.
Video.sala(id) Cria uma Room P2P (Mesh).
Video.live(id) Cria uma transmissão ao vivo (Streamer).
Video.assistir(id) Acessa uma transmissão (Viewer - Apenas recebe dados).
Video.reproduzir(url) Faz streaming (VOD) de um vídeo com suporte a saltos (seeking).
Video.enviar(arquivo) Faz upload multipart de um File.

Pronto para usar?

Basta importar a biblioteca diretamente no seu projeto via CDN. Não requer bundlers se você não quiser.

<script type="module">
  import { Video } from "http://localhost:3000/client/index.js";

  Video.configure({ signalingUrl: "ws://localhost:3000" });
</script>
