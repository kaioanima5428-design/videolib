Transmissões ao Vivo Live Broadcasting

Um transmite, muitos assistem. Economize banda usando o modo Live, onde espectadores apenas recebem o fluxo de dados sem sobrecarregar a rede do Streamer. One streams, many watch. Save bandwidth using Live mode, where viewers only receive the data stream without overloading the Streamer's network.

💻 Frontend (Navegador) 💻 Frontend (Browser) 
// No cliente que vai apenas assistir:
const live = await Video.assistir("gameplay-lol");

live.video(document.getElementById('player'));
await live.conectar();
// In the viewer client:
const live = await Video.watch("gameplay-lol");

live.video(document.getElementById('player'));
await live.connect();

O Servidor de Sinalização (Backend) The Signaling Server (Backend)

Para que os navegadores conversem entre si, precisamos de um servidor Node.js intermediário. A videolib faz o setup pesado para você. For browsers to talk to each other, we need an intermediary Node.js server. videolib does the heavy lifting for you.

⚙️ Backend (Node.js) ⚙️ Backend (Node.js) 
import express from 'express';
import { VideoServer } from '@caiomultiversando/videolib/server';

const app = express();
app.get('/', (req, res) => res.send('Meu App Express!'));

// 1. Sobe seu servidor normal
const httpServer = app.listen(3000);

// 2. Acopla o VideoServer nele (Sem conflito de portas!)
const video = new VideoServer();
video.videos('./meus-videos'); // Serve arquivos para VOD
video.anexar(httpServer);

Controles Avançados (Mute, Câmera e Tela) Advanced Controls (Mute, Camera and Screen)

A manipulação de mídia funciona em tempo real. Você pode substituir a câmera pela tela do PC sem derrubar a chamada. Media manipulation works in real-time. You can replace the camera with the PC screen without dropping the call.

💻 Frontend (Navegador) 💻 Frontend (Browser) 
// Mutar e Desmutar microfone
sala.mute();
sala.desmutar();

// Pausar o próprio vídeo (imagem preta)
sala.pausarCamera();
sala.retomarCamera();

// Compartilhar a tela do PC (Substitui a câmera local)
await sala.tela();

// Voltar para a câmera normal
await sala.pararTela();
// Mute and unmute microphone
room.mute();
room.unmute();

// Pause own video (black screen)
room.pauseVideo();
room.resumeVideo();

// Share PC screen (Replaces local camera)
await room.screen();

// Return to normal camera
await room.stopScreen();

Reconexão Automática (Backoff) Automatic Reconnection (Backoff)

A internet caiu? O usuário trocou do 4G para o Wi-Fi? A biblioteca tenta se reconectar sozinha e reentra nas salas. Internet dropped? User switched from 4G to Wi-Fi? The library tries to reconnect automatically and rejoins the rooms.

💻 Frontend (Navegador) 💻 Frontend (Browser) 
sala.on("reconectando", (info) => {
  console.log(`Conexão perdida. Tentando novamente... ${info.attempt}/${info.maxAttempts}`);
});

sala.on("reconectado", () => {
  console.log("Restaurado! Estamos de volta à sala.");
});
room.on("reconnecting", (info) => {
  console.log(`Connection lost. Trying again... ${info.attempt}/${info.maxAttempts}`);
});

room.on("reconnected", () => {
  console.log("Restored! We are back in the room.");
});

Referência da API Frontend Frontend API Reference

Método / Classe Method / Class Descrição Description
Video.configure(opts) Configura o WebSocket e URL do servidor. Configures the WebSocket and Server URL.
Video.chamada(id) / Video.call(id) Cria uma Call P2P 1x1. Creates a 1x1 P2P Call.
Video.sala(id) / Video.room(id) Cria uma Room P2P (Mesh). Creates a P2P Room (Mesh).
Video.live(id) / Video.stream(id) Cria uma transmissão ao vivo (Streamer). Creates a live broadcast (Streamer).
Video.assistir(id) / Video.watch(id) Acessa uma transmissão (Viewer - Apenas recebe dados). Accesses a broadcast (Viewer - Only receives data).
Video.reproduzir(url) / Video.play(url) Faz streaming (VOD) de um vídeo com suporte a saltos (seeking). Streams (VOD) a video with support for seeking.
Video.enviar(arquivo) / Video.upload(file) Faz upload multipart de um File. Uploads a File (multipart).
